Harga & Pengaturan

Harga Publikasi Undangan

Harga untuk order baru; harga order yang sudah dibuat tidak berubah.

Konfigurasi

Semua template memakai harga publikasi yang sama di MVP; harga berbeda berdasarkan role yang diverifikasi server.

Upgrade Reseller

Sekali bayar melalui QRIS, bukan langganan.

Harga disalin ke snapshot order saat dibuat. Voucher tidak berlaku untuk order upgrade.

Ringkasan aturan

  • Role reseller diberikan otomatis setelah webhook pembayaran tervalidasi berstatus paid.
  • Webhook duplikat tidak boleh menggandakan role atau audit event.
  • Admin tidak boleh menaikkan role dirinya sendiri menjadi admin.
  • Perubahan harga hanya memengaruhi order baru.
